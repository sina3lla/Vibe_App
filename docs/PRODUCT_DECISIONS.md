# Current Product Decisions

- Adopt an explorable educational self-help world as a companion to FeelY.
- The MMORPG reference is conceptual; multiplayer, 3D, quests and combat are not required.
- No chatbot or educational videos; understanding emerges through interaction with optional contextual explanations.
- Build a reversible first playable slice, then refine from owner feedback.
- Two complete color schemes: Bright and Dark. Default to silent system adaptation. Settings: Design → System, Bright, Dark; persist overrides without losing interaction state. No notification or information box.
- Release still requires login, explicit AGB acceptance, language selection, whole-app localization, Europe-first plus English. Other countries/languages remain undecided.
- Existing designs and guided-session briefs are superseded; archive/pre-explorable-world preserves history.
- The full automated Claude–Codex–Claude cycle is not yet verified. Fix/check infrastructure and update the old screen-specific QA before using it to verify the new world.
